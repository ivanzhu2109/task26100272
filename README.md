# synonym-archive

客服消息档案的同义短语检索库（Go）。数据驻留进程内，档案构建后只读，
由上层直接调用，支持「建档」与「单短语查询」两个操作。

## 功能

- 建档：`New(messages, rules)` 接收消息（唯一整数编号 + 词元序列）与
  固定的有方向同义规则，返回只读档案，可并发查询。
- 查询：`Query(phrase)` 对查询短语做一次同义替换展开（保留原查询，
  可选择任意个互不重叠、与某规则左侧完全相同的原查询片段替换为右侧；
  替换结果不再套用规则），任一展开与消息连续片段完全一致即命中。
- 计分：整个查询短语视为单一检索项，按 BM25 打分
  （tf 为消息中不同命中起点数，df 为至少命中一次的消息数，
  N/dl/avgdl 为档案固有统计），结果按得分降序、同分按编号升序。

## 使用

```go
a := archive.New(
    []archive.Message{{ID: 1, Tokens: []string{"a", "a", "a"}}},
    []archive.Rule{{From: []string{"a"}, To: []string{"a", "a"}}},
)
hits := a.Query([]string{"a", "a"}) // []archive.Hit{ID, Score}
```

## 运行测试

```sh
go test ./...        # 运行全部测试
go test ./... -v     # 查看各场景明细
```

测试覆盖：命中集合、tf（同一起点去重、重叠起点分别计数）、df、
排序（得分降序、同分编号升序）、BM25 得分公式逐项核对，
以及规格指定场景（查询 "a a" 下 tf=3/1、df=2）和
「替换结果不再套用规则」场景。

## 文件

- `archive.go` — 类型定义、建档、查询与命中统计
- `expand.go` — 查询的一次同义替换展开
- `score.go` — BM25 得分
- `archive_test.go` — 自动化测试
